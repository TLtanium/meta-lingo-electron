## 文案正文（可直接复制发布）

**【Meta-Lingo 大更新来了】**

语料库研究软件 Meta-Lingo 当前版本迎来一波重磅更新，从标注、分析到跨模块联动和 AI 助手，都有明显增强。整理成一篇方便大家一眼看完。

---

**一、标注与多模态**

- 英语音频波形标注：支持 Wav2Vec2 词级对齐 + TorchCrepe 音高曲线，在波形上直接画框标注。
- Praat 声学分析全线接入：频谱图、共振峰 F1–F5、强度、谐噪比 HNR、Jitter/Shimmer 一应俱全；上传时可选说话人性别（影响共振峰范围）。
- 中文音频也可完整看：波形 + 音高 + 频谱图 + 共振峰（不跑 Wav2Vec2 对齐）。
- 标注界面里频谱图、共振峰、强度、HNR 可单独开关；标注历史详情页展示频谱图与 Jitter/Shimmer 统计。
- 频谱图热力图修复并优化：改用 GPU 加速渲染与合理降采样，大语料下不再卡顿或空白；共振峰提取增加约束区间与中值滤波，曲线更稳。
- 编码者间信度「标准答案」功能修复；Theme/Rheme 自动标注与深色主题全面适配。

---

**二、分析模块增强**

- **新增参考语料库（全部）**：关键性对比现在可用多套预装参考语料作为对比基准，包括 BNC 1994、BNC 2014、Brown、NOW、OANC、COCA、COHA、GloWbE 等，覆盖书面/口语/多变体英语。每套语料均含词形、词元与 USAS 语义域统计，选哪套就能按哪种单位做关键性对比。
- **USAS 关键词对比**：关键性对比新增 **语义域 (USAS)** 模式——不再只比「词」谁多谁少，而是比「语义域」在你语料和参考语料中的分布差异。选好参考语料后，勾选「按语义域对比」，结果表会列出显著偏高/偏低的语义域（带域代码与完整名称），柱状图、饼图、词云都用语义域名称展示，支持按名称搜索和 CSV 导出，适合做语义风格、语域特征分析。
- **关键词·关键性对比**：除上述语义域模式外，仍支持 **词形** / **词元** 两种对比模式；左侧配置区有「对比模式」下拉，与参考语料库搭配使用即可。
- **语料库资源**：适配新 CSV 结构（word, lemma, pos, usas, freq），支持按词形/词元/语义域构建频率表；BNC 拆成 BNC1994 与 BNC2014，并为 COCA、COHA、GloWbE 等提供中英文名称；语料库卡片词数改为「总词符数」，与文档说明一致。
- **搭配分析**：MinSense 修正为 min(ΔP1, ΔP2)；词图对比支持词形/词元输入模式；搭配网络图支持点击搭配词展开该词的一层搭配，中心与展开层数量统一控制。
- **语义域分析**：按语义域统计时，每行可「查看共现关系」跳转共现并带 CQL；柱状图/饼图统一用语义域名称，MWE 合并；新增词云图。
- **共现关系 (CQL)**：支持语义域属性 `usas`（= 包含、== 精确），匹配时忽略 _MWE 后缀；CQL 构建器里可直接选 usas。
- **主题建模**：LDA/LSA/NMF 预处理增加 N-gram 模式（2–6 gram 可多选），并支持动态主题与主题流动/演化时间线；文献库模式下可用文献年份做动态主题；无自定义标签时主题名随界面语言显示（中文「主题1」/ 英文 「Topic 1」）；主题重命名可优先走 OpenAI 兼容 API。
- **同义词分析**：只保留「在所选语料中实际出现过的」同义词；同义词集详情按词展示释义，并支持从同义词跳转词频/共现/搭配等。
- **MIPVU 隐喻**：采用 HiTZ + Clause 小句模型混合方案，对功能词 (IN/DT/RB/RP) 用 clause-metaphor 模型补判；结果表展示来源标签与 IN/DT/RB/RP/OTHER 隐喻率，便于对比功能词与非功能词。

---

**三、跨模块与语料选择**

- **跨域链接**：词频、同义词、关键词（单文档+关键性）、共现、搭配、词图、N-gram、语义域、隐喻、主题建模（BERTopic/LDA/LSA/NMF）以及标注模式之间，均可互相跳转并带上当前语料/文献选择。
- **文献库模式**：从任意分析结果表跨链时，目标页会同步文献库、选择方式（全部/按关键词/手动）及已选条目；文献库下手动选择列表不再高频闪烁；搭配分析在文献库下的跨链与词频统计行为对齐。
- 标注表格菜单区分「搭配分析」与「词图分析」；N-gram 跨链时最小频率设为 1；转录文本点击定位时句子会滚动到可视区域中间。

---

**四、AI 与设置**

- **分析模块 AI 助手**：词频、同义词、关键词、共现、N-gram、搭配、词图、语义、主题建模等左栏右上角增加机器人图标；在 Ollama 已连接或 OpenAI 兼容 API 开启时可点，弹窗对话会把当前语料、参数和视图内容作为上下文，方便问「怎么解读」「参数怎么设」等。
- **OpenAI 兼容 API**：设置里新增开关与配置（地址、Key、模型），支持测试连接；可用于主题命名等；恢复出厂设置会一并清零这些 API 设置。
- **语料库构建脚本**：`saves/corpus/corpus_building.py` 支持 13 个英语语料库（BNC/Brown/NOW/OANC/COCA/COHA/GloWbE 等），用 SpaCy + PyMUSAS 做 PTB POS、词元与 USAS 标注，输出 `word,lemma,pos,usas,freq` CSV，交互式菜单按语料/类别处理，自动跳过已含 usas 的 CSV。

---

**五、体验与修复**

- 结果表搜索框在翻页后仍可正常搜索（词频、同义词、N-gram、语义域、隐喻、搭配等）。
- N-gram 分页总数按过滤后数据计算；跨链到共现时 N-gram 中心词整段高亮；搭配/词图跨链共现时词形与词元匹配逻辑修正，避免无结果。
- 词操作菜单统一增加「查看搭配分析」「N-gram 分析」「语义域分析」等入口；Keyness 统计阈值改为自定义 +/- 控件；多处「转小写」、频率范围、section 间距等 UI 统一。
- 未加载语料库时删除存档可用（用存档自身的 corpusName）；标注历史里音频柱状图与文本分块展示、留白与高度调整。
- 山脊图支持最多 50 个文档、ResizeObserver 自适应；CQL 支持顶层 OR、模板点击自动填充；PNG 导出通过 SVG→Canvas 保证滚动区域完整导出。
