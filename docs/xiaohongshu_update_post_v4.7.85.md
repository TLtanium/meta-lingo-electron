## 文案正文（可直接复制发布）

---

**【Meta-Lingo 当前版本更新｜语料研究桌面软件：更小、更顺、更敢接外部 AI】**

如果你用语料库做语言学或应用语言学研究，这一版把 **拿到软件、装进电脑、接上你熟悉的 AI、做完一整条研究链路** 都往前推了一步。下面是按「你会感受到什么」写的更新说明，方便你决定要不要升级。

---

**一、用 Claude、Cursor 等，直接驱动 Meta-Lingo 做研究**

- 在应用 **设置 → MCP 服务** 里打开开关后，Meta-Lingo 会作为 **MCP 服务** 对你本机上的 **Claude Desktop、Cursor 等支持 MCP 的 AI 应用** 开放能力。
- 对你来说的意义是：**不用在软件里逐项点菜单**，也能让外部 AI 帮你完成建库、上传、词频与关键词、语境检索、语义域、搭配与导出等 **一整条研究工作流**；工具按语料管理、分析、标注等模块分组，数量以应用内说明为准。
- **上手方式**：设置里可 **下载扩展包（.dxt）** 一键接到 Claude Desktop，或按说明复制配置到其它客户端。网页版 AI 若要走公网连接，需自行解决网络可达性；**本机桌面客户端**一般最省事。

---

**二、官网下载与体积：从「一次下 40G」到「先装 2G，再按需补模型」**

- **下载方式变了**：官网提供 **安装包直链**，**不再把百度网盘当作主下载渠道**。大陆网络若直连偏慢或中断，可用官网给出的 **备用网盘直链**（**免登录、不限速**，以官网当期页面为准）。
- **体积更友好**：过去整体分发接近 **40GB「全家桶」** 的体验，现在调整为 **约 8GB 量级的安装体**；首次拿到的 **压缩包约 2GB**（以官网实际发布为准），先装软件再决定要不要拉满模型。
- **模型自己说了算**：**设置**里新增 **「模型管理」**。语音识别、视频物体检测、图像语义、句向量、语义域与隐喻等用到的 **大体积模型**，都可以在应用里 **按需下载或删除**，不占满整块硬盘。
- **安装与补模型**：基础安装与在应用内拉取模型，**一般不需要额外网络工具**（以你本地网络与应用内提示为准）。

---

**三、建库语言：11 种可选，但每条分析线能力不同（请务必读完）**

创建语料库时要在元数据里选定 **「主语言」**。与手册一致，当前支持 **11 种**（也是后续 **SpaCy / USAS / 音频流水线默认可直接衔接** 的语言集合）：


| 界面中的语言                               | 说明（便于你对照论文或语料来源）                              |
| ------------------------------------ | --------------------------------------------- |
| 英语                                   | 能力最全的一条线（见下文「仅英语」模块）                          |
| 中文                                   | 与英语同属「规则型 USAS 可优先」的语言                        |
| 丹麦语、荷兰语、芬兰语、法语、意大利语、葡萄牙语、俄语、西班牙语、瑞典语 | 欧洲语言统一走 **新闻领域小型模型** 管线；USAS 以 **多语言神经模型** 为主 |


**为什么要盯紧「主语言」**：它决定 **自动标注用哪套 SpaCy 模型**、**USAS 走规则优先还是直接神经**、以及 **音视频上传后的默认可用能力**。下面按 **你实际会点开的模块** 说明，避免「建库成功 ≠ 每个按钮都能用」。

---

**四、语境索引（共现 / KWIC）：新 CQL 搭建方式，并接上词图与情感标签**

- **新的 CQL 构建器**：用可视化方式拼查询条件，少手写、少试错，从「我想找这类搭配」到「生成可执行的 CQL」更顺。
- **检索能力扩展**（与手册「语境索引」一致）：支持 **结构标记**（句 / 段 / 文档层级）、**within / containing / meet** 等位置关系，以及 **词图模板 `ws()`**（与 **词图分析** 联动）、在索引里使用 **NRC 情感相关属性** 等，方便从 **搭配 → 语境 → 情感线索** 一条线查下去。
- 与 **词频、语义域、搭配、词图** 等模块的 **互相跳转** 继续对齐，减少复制粘贴和来回切窗口。

---

**五、标准界面 ↔ 对话界面，以及「Lemy」是啥**

- 顶栏可在 **标准模式**（传统多标签：语料库、词频、语境索引、语义分析等各模块）与 **对话模式**（用自然语言描述任务）之间切换。
- **对话模式**下，配置好 **Ollama** 或 **OpenAI 兼容接口** 后，可以用口语化指令让助手 **自动选用内置工具链** 完成分析；对话记录可 **长期保存**，方便复现和改口径。
- **Lemy** 就是对话里那个会跟你打招呼、加载时碎碎念、偶尔在报错文案里刷存在感的小助手——界面上的「人格」和语气担当，**不是**要你再买一份的独立模型。真正干活、背锅算力的，还是你在设置里接好的 **Ollama / OpenAI 兼容接口**；把它想成给冷冰冰的工具栏套了个壳，排队跑分析时至少有人陪你说两句。

---

**六、USAS 语义域：标注方式统一，和「参考语料」对齐口径**

- 应用内 **统一用神经网络模型做 USAS 语义域标注**，默认对每个词位给出 **至多 5 个候选标签（top_n=5）**，统计与下游分析与该设定一致；若关闭「消歧」时的多标签行为，以 **设置 → USAS** 与手册为准。
- **内置参考语料库**（用于 **关键词「关键性」对比** 等）里的 USAS 数据，也按 **同一套神经模型 + 同一 top_n 策略** 构建，保证 **你的研究语料** 与 **参考语料** 在语义域维度上 **口径一致、可比**。
- **关于「准确度约 90%」**：在公开技术说明中，该类多语言语义模型常见 **top-1 / top-5** 指标；在典型设定下 **top-1 约 90% 量级** 可作为文献与模型卡上的参考，**实际以你的文本类型与任务为准**，不宜写成「任何语料都固定 90%」。

---

**七、关键性对比等新场景：更多「官方参考语料」可选**

在既有 BNC、COCA、GloWbE 等资源之外，**参考语料库资源库**中新增或完善可选用语料（名称以应用内列表为准），例如：


| 名称（应用内）         | 适合用来做什么（概括）  |
| --------------- | ------------ |
| **Coronavirus** | 疫情相关主题的对比与参照 |
| **iWeb**        | 大规模网络英语参照    |
| **Movies**      | 电影文本风格参照     |
| **SOAP**        | 肥皂剧类对话体参照    |
| **TV**          | 电视文本参照       |
| **Wikipedia**   | 百科体书面语参照     |


用于 **关键性对比**、资源说明卡片、与自建语料并置分析等；各库的 **时间范围、规模与词条说明** 以应用内卡片与手册为准。
