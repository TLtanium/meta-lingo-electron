# Lemy artwork

lemy.png is the user's existing Lemy sprite sheet, reused with the creator's authorization. It is the 1536 × 2288 v2 atlas (8 columns, 11 rows; 192 × 208 cells). No new artwork is generated. Animation metadata is in src/pet/atlas.ts. The application uses a bundled local copy, never an expiring pet-service URL.
