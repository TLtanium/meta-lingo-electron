### 详细四维判断 (Top PD 条目)

**① "building blocks" — 全信核心扩展隐喻 (S77, S79, S114, S155, S166, S168, S172, S173, S174, S180)**
- **Linguistic**: **DIRECT** + MFLAG: **yes** ("Think of them as..." S77; "think of it as a core building block" S155)
- **Conceptual**: **novel** — 将技术组件（AWS 服务、物流能力、AI 模型）系统地映射为乐高式的建筑积木
- **Referential**: **DR** — "building blocks"在字面上构造了物理积木/建筑组件的场景；"weave together"（纺织/编织）进一步丰富了源域
- **Discourse**: **EXTENDED METAPHOR** —— 这是全信的核心修辞结构。"primitives"概念通过 building blocks 隐喻贯穿全文（S77→S79→S97 backbone→S114→S155→S166→S168→S172→S174→S180 tool chest→S181 lynchpins），构成 Amazon 技术哲学的统一隐喻框架
- **Communicative**: Jassy 用"基元/积木"隐喻来回答"Amazon 为什么能持续创新"这个根本问题。building blocks 隐喻让技术架构变得直观可视，是刻意选用的核心修辞策略
- **判断**: **POTENTIALLY DELIBERATE** ✅ — 最高确信度。这是全信唯一的扩展隐喻主干，13 次出现 + MFLAG 信号 + DIRECT 形式

### 跨句隐喻集群小结

2023 年信的核心刻意隐喻是**唯一的扩展隐喻主干**——**"基元即积木"**（Primitives as Building Blocks）：

- **入口** (S77): "Think of them **as** discrete, **foundational building blocks** that builders can **weave together**"
- **展开** (S97): "use Amazon's ecommerce components **as** the **backbone**"
- **深化** (S114): "AWS **unveiled** these **building blocks**... whole companies **sprang up** on top of AWS"
- **再强调** (S155): "think of it **as** a **core building block**"
- **扩展至物流** (S166): "Highly flexible **building blocks** can be **composed** across businesses"
- **扩展至医疗** (S168, S172): "we've **unveiled** how these **building blocks** come together"
- **扩展至机器人** (S180): "build the **tool chest** to compose more freely"
- **扩展至 AI** (S189): "three distinct **layers** in the GenAI **stack**"

**核心功能**：Jassy 用 building blocks 隐喻解释 Amazon 的**基元架构哲学**——可组合、可复用、可扩展。这不是一个装饰性隐喻，而是全信的概念骨架。他通过这个隐喻将 AWS、物流、医疗、AI 等多元业务统一到一个共同的技术哲学下。

**与 2021-2022 年信的关系**：2021 年信的核心隐喻是"迭代式创新的复利效应"；2022 年是"变化即访客"/"创新即杂乱过程"；2023 年则是"基元即积木"——每一封信都有一个独特的扩展隐喻锚点。
