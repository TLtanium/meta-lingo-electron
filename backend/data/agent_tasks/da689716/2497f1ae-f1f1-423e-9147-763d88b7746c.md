### 刻意隐喻 #1 — "must think like, and therefore must actually be, an owner"
| 维度 | 分析 |
|------|------|
| **MRW** | owner / like |
| **位置** | S41 |
| **语言维度** | DIRECT + MFLAG |
| **概念维度** | 新颖——雇佣关系中被要求"成为所有者"，重新映射劳资关系 |
| **指称维度** | **DR** — 合格读者会想象出"所有者"的场景（主人关心自己产业的态度） |
| **话语特征** | 高层面谓词；MFLAG存在；从句法上从比喻(think like)推进到字面断言(must actually be) |
| **判断** | **刻意隐喻 ✅** |
| **置信度** | 高 |
| **证据** | 贝佐斯在此句中使用MFLAG"like"引出"owner"作为直接隐喻，然后立即转为字面断言（通过期权使员工真正成为所有者）。这种从比喻到字面的折返是刻意隐喻的经典信号。该句位于资本配置哲学的核心段落，表达了"员工即主人"这一独特的企业文化理念。 |
