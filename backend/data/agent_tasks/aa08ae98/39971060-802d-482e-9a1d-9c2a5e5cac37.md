### 核心话语模式

**2016年信是全系列最关键的管理哲学文献**：

**「Day 2」作为新概念**：Bezos首次明确定义Day 2——不是轻松的日子，而是"stasis → irrelevance → excruciating painful decline → death"。这是对1997年"Day 1"概念的补充，形成了完整的Day 1/Day 2二分法框架。

**四大防御策略**：customer obsession → resist proxies → embrace external trends → high-velocity decision making。

**DIR密度极低**（仅1个DIR——1997信附录中的"think like an owner"），刻意隐喻主要通过概念新颖性（Day 2的死亡链）而非DIR/MFLAG来实现。
